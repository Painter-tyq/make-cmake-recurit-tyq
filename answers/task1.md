# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
2. 编译
3. 汇编
4. 链接

建议控制在 300～500 字，不需要展开复杂细节。

1. **预处理（gcc -E）**
处理所有以#开头的预处理指令，展开#include头文件，替换#define宏定义，删除注释,生成.i文件。这个阶段只做文本替换，还没有生成真正的汇编代码。

2. **编译（gcc -S）**
把预处理后的C代码，翻译成汇编语言代码（.s文件）。会进行语法检查、词法分析、语义分析，如果代码有语法错误，会在这一步报错。

3. **汇编（gcc -c）**
把汇编代码翻译成机器能识别的二进制目标文件（.o文件，目标文件），此时还不能直接运行。

4. **链接**
把多个.o目标文件，还有依赖的库文件合并，解析函数引用，分配地址，最终生成完整、可以直接运行的可执行文件。

### 执行记录
执行命令：
```bash
gcc -E hello.c > hello.i    # 预处理
gcc -S hello.c > hello.s    # 编译，生成汇编代码
gcc -c hello.c > hello.o    # 汇编，生成二进制目标文件
